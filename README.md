# Blank Screen — Gemini Aurora

A single minimalist blank screen: **Aurora Curtains** — flowing sine curtains
colored with Google Gemini's 4 signature colors:

- **Blue** `#4285F4`
- **Green** `#34A853`
- **Yellow** `#F9AB00`
- **Red** `#EA4335`

The four colors cycle smoothly across the screen and flow with time, driven by
per-pixel layered sine curtains with fbm turbulence (240×135 buffer, upscaled
shader-style). Honors `prefers-reduced-motion` (one static frame) and pauses
when the tab is hidden.
